# Sua prova — primeiros passos

1. **Edite `ALUNO.md`** com seu nome/RA (o workflow valida).
2. **Abra a [issue 🎯 Prova](https://github.com/BrunoNovodovoski-05/Prova_2026/issues/1)** — é nela que tudo acontece.
3. **Selecione sua prova** comentando `/track <nome>` na issue (a lista está no comentário de boas-vindas).
4. A prova é aplicada no repo (overlay); desenvolva e dê push. **Pushes não disparam correção** — quando quiser feedback, rode `/auto-correcao` na issue.
5. **Feche a issue para encerrar** — o sistema só aceita o fechamento depois de ao menos 1 `/auto-correcao` e gera o `teacher.json` de entrega.
